# Quantum Launcher

**Quantum Launcher** — быстрый, современный и лёгкий лаунчер Minecraft. Это форк [Modrinth App](https://github.com/modrinth/code) доработанный для максимальной производительности, оффлайн-авторизации и удобного UI.

Разрабатывает [@ivanmaspa](https://github.com/ivanmaspa).
